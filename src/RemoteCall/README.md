# 远程消息 RemoteCall

局域网内其它设备（手机 / 平板 / 另一台电脑）通过网页向本机 **ClassIsland** 发送消息，
本机以**主界面组件**轮流展示，并在收到新消息时弹出 **ClassIsland 标准提醒**（遮罩 + 正文涟漪动画，和上下课提醒一致）。

## 功能

- 局域网网页端（默认 `8000` 端口）：密码登录、可记住登录状态；发消息；看历史消息（含已完成 / 未完成）、发送者 IP 与设备名。
- 设备名可改，改完后该设备的历史消息会同步显示新名字。
- 网页上可把某条消息标记为「已完成展示」，本机同步标记，组件默认不再轮播它。
- 本机管理页（`http://127.0.0.1:8199/`，仅本机可访问）：管理历史消息、设备名、访问密码、端口与服务开关。
- 全部设置也可以在 **应用设置 →「远程消息」** 里改，保存后立即生效。
- 主界面组件一屏显示一条消息，**每 5 秒向上滑动切换**到下一条（间隔、动画时长、显示高度可在组件设置里改）。
- 收到新消息时的提醒：遮罩阶段显示「新消息 · 设备名」（涟漪特效），之后的正文**静止**显示消息内容；可通过设置页开关，遮罩 / 正文时长、是否朗读均可调。

## 首次使用

1. 启动 ClassIsland，打开「应用设置 → 远程消息」。
2. 默认访问密码是 **`admin`**（页面会显示，强烈建议改成自己的密码；也可以点「随机生成」）。
3. 在「应用设置 → 组件」里把「远程消息」组件拖到主界面（安装脚本加 `-AddComponent` 时会自动放到第一行）。
4. 手机连接同一个局域网，访问应用设置里「局域网访问地址」给出的地址，用 `admin` 登录即可发消息。
5. 如果手机打不开网页，请检查 Windows 防火墙是否允许 `ClassIsland.exe` 接收入站连接。

## 文件位置

- 插件本体：`<ClassIsland 目录>\data\Plugins\remote.call\`
- 配置与数据：`<ClassIsland 目录>\data\Config\Plugins\remote.call\`
  - `settings.json`：端口、密码哈希、提醒设置
  - `store.json`：历史消息与设备
  - `sessions.json`：登录会话（只保存令牌哈希）

## 注意

- 网页使用明文 HTTP，**只适合在可信局域网内使用**，不要把端口映射到公网。
- 密码以 PBKDF2-SHA256 加盐哈希保存，磁盘上没有明文密码；默认密码 `admin` 为了便于查看会明文保存在 `settings.json` 的 `GeneratedPassword` 里，改成自己的密码后会被清空。
- 「局域网访问地址」只列出真实网卡（VMware / Hyper-V / Radmin / Tailscale / WSL 等虚拟网卡会被过滤掉），手机连不上虚拟网卡的地址。
- 端口被占用时设置页会显示具体原因，换一个端口即可。
