## 远程消息 RemoteCall 1.0.0.0

局域网内其它设备（手机 / 平板 / 另一台电脑）通过网页向本机 **ClassIsland** 发送消息，
本机以**主界面组件**轮流展示，并在收到新消息时弹出 **ClassIsland 标准提醒**（遮罩 + 正文涟漪动画）。

### 功能

- **局域网网页**（默认 `8000` 端口）：密码登录、可记住登录；发消息；查看历史（含已完成 / 未完成）、发送者 IP 与设备名。
- **设备名自动识别**：按 User-Agent 识别 `iPhone` / `iPad` / Android 机型 / `Windows 电脑` / `Mac` 等，也可一键改名，历史同步更新。
- **完成展示**：网页上可把某条消息标记为「已完成展示」，本机同步标记，组件不再轮播它（历史仍保留）。
- **本机管理页**（`http://127.0.0.1:8199/`，仅本机）：历史增删、设备改名、改密码、改端口、重启监听。
- **全部设置也可在 ClassIsland 内修改**：应用设置 →「远程消息」，保存后 0.3 秒内热切换监听。
- **组件**：一屏显示一条消息，每 5 秒向上滑动切换，间隔 / 动画时长 / 高度可调。
- **提醒**：遮罩阶段显示「新消息 · 设备名」（涟漪特效），随后的正文静止显示消息内容；时长与语音朗读可调。
- **默认密码**：`admin`（首次启动自动设置，强烈建议修改）。
- 支持「不限制」：记住登录天数、历史保留条数填 `-1` 即无上限。

### 安装

1. **插件市场**（推荐）：ClassIsland 2.1 及以上 → 应用设置 → 插件 → 插件市场，搜索「远程消息」安装。
2. **手动安装**：下载本 Release 的 `RemoteCall.cipx`，在 应用设置 → 插件 中从文件安装；
   或把 `.cipx`（本质是 zip）解压到 `<ClassIsland>\data\Plugins\remote.call\`。

安装后重启 ClassIsland。手机连接同一局域网，打开 应用设置 →「远程消息」里显示的局域网地址（默认 `http://<电脑IP>:8000/`），用 `admin` 登录。

### 说明

- 仅在 **Windows** 上实测（net8.0 / ClassIsland 2.1.0.1）。
- 首次监听时若 Windows 防火墙弹窗，请允许 `ClassIsland.exe` 接收入站连接。
- 网页使用明文 HTTP，请在可信局域网内使用，不要映射到公网。
